# Règles du projet

## Gestionnaire de paquets

- **pnpm est le seul gestionnaire de paquets autorisé.** `npm` ne doit jamais être utilisé seul (ni `npm install`, ni `npm run`, ni aucune autre commande npm), pour des raisons de sécurité.
- Toujours utiliser les équivalents `pnpm` : `pnpm install`, `pnpm run <script>`, `pnpm add <package>`, etc.
